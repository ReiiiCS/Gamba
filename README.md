# PLAYROOM

A responsive, free-to-play game discovery site built with React, TypeScript, and Vite. The Neon Vault case-opening demo uses virtual items only: there are no purchases, accounts, deposits, prizes, or cash-outs.

## Notice

PLAYROOM is a fictional entertainment demo, not a gambling service. It does not accept or involve real money, offer items with monetary value, or award prizes. Case openings are simulated for fun only; there are no deposits, purchases, withdrawals, or cash-outs.
