# PLAYROOM

A responsive, free-to-play game discovery site built with React, TypeScript, and Vite. The Neon Vault case-opening demo uses virtual items only: there are no purchases, accounts, deposits, prizes, or cash-outs.

## Notice

PLAYROOM is a fictional entertainment demo, not a gambling service. It does not accept or involve real money, offer items with monetary value, or award prizes. Case openings and European roulette spins are simulated for fun only; roulette uses pretend chips with no cash value. Each roulette number has a 1-in-37 chance, standard European payouts are used, and the 2.70% house edge is shown in-game for educational purposes. There are no deposits, purchases, withdrawals, or cash-outs.
